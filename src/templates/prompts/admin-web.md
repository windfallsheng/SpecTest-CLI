管理后台 Web 端专属用例标准：

1. **权限矩阵**：按角色×资源逐项验证可见性/可操作性（超管/普通管理员/只读角色）；越权直接 URL 访问单独成例。
2. **列表页**：筛选组合、排序、分页边界（首页/末页/空页）、批量操作勾选状态。
3. **表单页**：新增/编辑复用、校验、脏数据离开提示、提交失败数据保留。
4. **操作确认**：危险操作二次确认、撤销/回滚。
5. **数据字典**：枚举下拉、级联选择（省市区）、树形结构的边界场景。
6. **导入导出**：格式校验、大文件、超时、失败重试。
7. **审计日志**：关键操作留痕断言。
8. **响应式**：1366×768 / 1920×1080 两档布局验证。

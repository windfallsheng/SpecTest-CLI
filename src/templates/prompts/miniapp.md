小程序端专属用例标准：

1. **生命周期**：lifecycle 字段标注时机（onLaunch/onLoad/onShow/onHide/onUnload），冷启动、热启动、后台切前台的状态恢复单独成例。
2. **平台矩阵**：platform 字段标注目标平台（微信/支付宝/抖音等），各平台 API 差异与容器特性差异场景。
3. **分包加载**：主包/分包边界、分包预下载、首次进入分包加载态与失败重试。
4. **授权体系**：首次申请/拒绝/拒绝后再引导，scope 变更后的适配（授权弹窗仅首问的降级路径）。
5. **登录态**：静默登录（code 换取）、token 失效重新登录、登录态跨页面传递。
6. **网络与缓存**：弱网（超时/断网重连）、storage 上限与清理、缓存过期刷新。
7. **分享与回流**：分享参数携带、场景值（scene）解析、分享进入后的落点路由。
8. **版本兼容**：基础库版本差异降级（新 API 能力检测）、灰度版本行为一致。
